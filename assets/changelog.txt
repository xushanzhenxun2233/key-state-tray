椰子味的魈宝键盘精灵  v1.0
更新日志

by 椰子味


▍ 状态指示
─────────────────────────────
1. 大写锁定（CapsLock）实时显示
2. 数字锁定（NumLock）实时显示
3. 输入法中英状态：中文绿底黑字「中」，英文红底黑字「英」
4. 状态块采用「主值 + 小标题」两行排版，余光可辨
5. 锁定键改用 GetKeyState 读取，不受窗口焦点影响
6. 输入法检测兼容微软拼音等纯 TSF 输入法


▍ 面板外观
─────────────────────────────
1. 支持自定义 PNG 皮肤，素材直接内嵌无需外部文件
2. 分层窗口逐像素 Alpha 合成，圆角边缘真实透明
3. 高 DPI 适配，150% / 200% 缩放下尺寸与文字均正确
4. 五档面板大小：特小 / 小 / 中 / 大 / 特大
5. 方形满幅托盘图标，视觉饱满清晰


▍ 面板控制
─────────────────────────────
1. 左键拖动面板，位置自动记忆
2. 拖动时实时约束在屏幕工作区内
3. 永不遮挡任务栏、永不拖出屏幕
4. 一键回到屏幕右下角
5. 首次启动默认落在右下角


▍ 智能透明度
─────────────────────────────
1. 不透明度 20%~100% 九档可调
2. 状态变化时自动恢复完全不透明，确保看清
3. 闲置指定时长后平滑淡出
4. 保持时长 1~30 秒可调
5. 永不透明开关，一键关闭淡出
6. 仅响应状态变化，打字与移动鼠标不会常亮


▍ 游戏模式
─────────────────────────────
1. 自动检测全屏应用（游戏 / 播放器）
2. 全屏期间自动隐藏面板，避免遮挡画面
3. 退出全屏后自动恢复显示
4. 已排除桌面、任务栏等系统窗口，避免误判


▍ 菜单交互
─────────────────────────────
1. 系统默认字体与尺寸，观感紧凑统一
2. 三种关闭方式：点选项 / 点空白处 / 按 Esc
3. 菜单期间启用全局钩子，解决面板无焦点导致无法关闭的问题


▍ 系统集成
─────────────────────────────
1. 常驻系统托盘，任务栏零占用
2. 支持开机自动启动（写入 HKCU，无需管理员）
3. 单实例保护，重复启动自动忽略
4. 配置与程序同目录，绿色免安装


▍ 分发与文档
─────────────────────────────
1. 提供完整版与脱敏版两个独立版本
2. 完整版含作者信息，脱敏版不含任何身份信息
3. 两版配置各自独立，可分别使用
4. 一键构建脚本，同时生成两版
5. 首次运行自动弹出本更新日志
6. 脱敏版署名可点击弹出联系二维码


▍ 技术信息
─────────────────────────────
1. 语言：C# 4.0
2. 框架：.NET Framework 4.0
3. 界面：WinForms + 分层窗口（逐像素 Alpha）
4. 图形：GDI+ / System.Drawing
5. 编译：csc.exe 单文件编译
6. 体积：约 800 KB，无外部依赖
7. 安全：不联网、不收集数据、不修改系统设置


▍ 问题修复
─────────────────────────────
1. 面板显示为纯黑 —— 改用逐像素 Alpha 合成
2. 高 DPI 下面板被缩小 —— 启用 DPI 感知并关闭自动缩放
3. 面板不显示 —— 异常写入 crash.log 便于定位
4. 托盘图标出现彩色噪点 —— 改为 ICO 直接切片不重绘
5. 菜单中 & 符号丢失 —— 转义为 &&
6. 点选项后菜单不关闭 —— 恢复 AutoClose 并加显式兜底
7. 点空白处菜单不消失 —— 菜单期间启用全局钩子
8. 首次启动位置跑到左上角 —— 修正默认落点为右下角
