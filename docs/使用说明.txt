一款带桌面宠物的键盘状态悬浮指示器。常驻托盘，实时显示锁定键
与输入法状态，桌宠「魈」可点击互动、可喂食、会自己走动。

本版本为脱敏版，不含作者姓名，适合分享给他人。


──────────────────────────────────────────────────────────────
 一、核心特性
──────────────────────────────────────────────────────────────

◆ 状态指示
  · 大写锁定（CapsLock）
  · 数字锁定（NumLock）
  · 输入法具体名称
      中文系（拼音、注音）  绿底黑字
      外语（英语、日语等）  红底黑字
  · 直接读取系统键盘布局，准确反映当前输入法

◆ 桌面宠物「魈」
  · 站在状态框上方，与框体合并为一个整体窗口
  · 8 种表情：吃东西 / 待机 / 眨眼 / 冷漠 / 睡觉 / 啧 / 思考 / 来吧
  · 待机时每 1~3 分钟自动切换表情
  · 点击随机说一句游戏原声台词（40+ 句官方原文）
  · 双击触发搞怪表情
  · 气泡对话独立显示在头顶，不遮挡魈

◆ 喂食系统
  · 饥饿值随时间增长，速度可在菜单调整
  · 饥饿时桌面掉落杏仁豆腐，拖到魈身上即可喂食
  · 极度饥饿时会说「雪积起来之后，就可以挖着吃了。」
  · 喂食后饥饿归零，播放吃东西动画

◆ 自动游走
  · 每 1~3 分钟沿曲线挪动一小步（约 1/8 屏）
  · 带方向惯性，不会来回反复横跳

◆ 整点提醒
  · 每到整点说一句时段问候
  · 分时段文案：早安 / 喝水 / 吃饭 / 休息眼睛 / 收工

◆ 主题化面板
  · 自定义 PNG 皮肤，逐像素 Alpha 合成，无黑边
  · 尺寸预设：小 / 中 / 大 / 大肥鸟
  · 右键菜单自动跟随系统深色 / 浅色主题
  · 素材与图标全部内嵌 exe，单文件分发

◆ 智能透明度
  · 状态变化或出现对话时自动完全不透明
  · 闲置时自动淡出到设定值
  · 淡出延迟可在菜单调整


──────────────────────────────────────────────────────────────
 二、快速开始
──────────────────────────────────────────────────────────────

1. 把 exe 放到任意文件夹（建议固定位置）
2. 双击运行
3. 面板与魈出现在屏幕右下角
4. 托盘出现图标，右键可打开全部设置

纯绿色软件，无需安装，不写系统目录。


──────────────────────────────────────────────────────────────
 三、操作指南
──────────────────────────────────────────────────────────────

◆ 移动窗口
  · 左键按住【魈】或【状态框】拖动
  · 拖动时自动限制在屏幕内，不会盖住任务栏
  · 松开后自动记忆位置

◆ 点击魈
  · 单击：随机换表情 + 说一句台词（约 3 秒）
  · 双击：触发搞怪表情

◆ 喂食
  · 饥饿时桌面会出现一份杏仁豆腐
  · 用鼠标拖动杏仁豆腐到魈身上
  · 魈会变成吃东西表情并说台词

◆ 右键菜单
  · 在【魈】或【状态框】上右键
  · 子菜单支持右键直接展开，无需悬停等待
  · 点击菜单外部或按 Esc 关闭

◆ 托盘图标
  · 单击：显示 / 隐藏面板
  · 右键：完整菜单


──────────────────────────────────────────────────────────────
 四、右键菜单说明
──────────────────────────────────────────────────────────────

▶ 回到屏幕右下角
    一键归位，归位后 1~3 分钟内不会自动游走

▶ 尺寸
    小（120）/ 中（180）/ 大（260）/ 大肥鸟（360）
    放大一级 / 缩小一级：每次调整 30px

▶ 闲置透明度
    100% 不透明 ~ 20% 最淡，共 8 档
    永不透明：彻底关闭淡出

▶ 保持完全不透明的时间
    状态变化后保持清晰的时间，1~30 秒

▶ 全屏游戏时自动隐藏
    检测到全屏应用时隐藏，退出后自动恢复并回到右下角

▶ 让桌宠打个招呼
    立即随机换表情 + 说话

▶ 自动游走
    开关桌宠的自动移动

▶ 饥饿速度
    5 秒/点（极快）~ 10 分钟/点（慢），共 7 档
    默认 45 秒/点，约 75 分钟从饱到全饿

▶ 整点提醒
    开关整点问候

▶ 喂食 · 杏仁豆腐
    直接喂食，不用等掉落

▶ 隐藏面板


开关类菜单项的状态显示：
    ✔  绿色加粗  = 已开启
    ✘  灰色常规  = 已关闭
    ☑  勾选标记  = 已选中


──────────────────────────────────────────────────────────────
 五、智能透明度详解
──────────────────────────────────────────────────────────────

◆ 两种状态
  · 活跃：完全不透明
  · 空闲：淡出到设定值

◆ 触发活跃的条件
  · 锁定键状态变化
  · 切换输入法
  · 出现对话气泡
  · 点击面板或菜单

◆ 保持时长
  活跃后保持「保持完全不透明的时间」所设秒数，
  然后平滑淡出。

◆ 关闭淡出
  菜单 → 闲置透明度 → 永不透明

 七、开机自启
──────────────────────────────────────────────────────────────

写入位置：
  HKCU\Software\Microsoft\Windows\CurrentVersion\Run

注意：自启路径与 exe 位置绑定。
      移动了 exe 所在文件夹后，需重新勾选一次。


──────────────────────────────────────────────────────────────
 八、配置文件
──────────────────────────────────────────────────────────────

程序会在 exe 同目录生成 XiaoBaoKeySprite.ini

主要配置项：
  caps / num / ime     是否显示对应状态块
  width                面板宽度
  opacity              闲置透明度 20~100
  nofade               永不透明 0/1
  hold                 保持完全不透明秒数
  hideingame           全屏游戏时隐藏 0/1
  showpet              是否显示桌宠
  petwalk              自动游走 0/1
  hunger               当前饥饿值 0~100
  hungerrate           饥饿速度（秒/点）
  feedcount            累计喂食次数
  hourlyremind         整点提醒 0/1
  x / y                面板位置

删除该文件 → 恢复全部默认设置。


──────────────────────────────────────────────────────────────
 九、关于杀毒软件误报
──────────────────────────────────────────────────────────────

本程序会执行以下操作，可能触发启发式告警：

  · 读取键盘锁定键状态
  · 读取当前输入法（键盘布局）
  · 写入开机自启注册表（仅勾选时）
  · 创建全局鼠标钩子（仅用于菜单关闭检测）

以上均为正常功能实现，程序：
  · 不联网
  · 不收集任何数据
  · 不修改系统设置（除自启项）

若被拦截，请添加白名单：
  Windows 安全中心 → 病毒和威胁防护 → 管理设置
  → 排除项 → 添加或删除排除项 → 添加文件夹

──────────────────────────────────────────────────────────────
 十一、常见问题
──────────────────────────────────────────────────────────────

Q：输入法显示的名称不对？
A：程序读取的是系统键盘布局。若显示「其他」，说明该输入法
   使用了非常见语言 ID，可反馈以便补充。

Q：魈不说话了？
A：检查是否处于游戏模式（面板被隐藏）。退出全屏后恢复。

Q：饥饿值涨得太快 / 太慢？
A：右键菜单 → 饥饿速度，有 7 档可选。

Q：怎么快速测试功能？
A：点击菜单顶部署名，打开「联系我」对话框，
   里面有 4 个测试按钮：整点报时、饥饿拉满、游戏隐藏、游走。

Q：面板不见了？
A：1. 单击托盘图标切换显示
   2. 或托盘菜单选择「面板回到屏幕右下角」
   3. 检查是否进入了全屏游戏

Q：可以在多台电脑使用吗？
A：可以。exe 为单文件，复制到任意 Windows 电脑双击即可，
   配置各自独立。
