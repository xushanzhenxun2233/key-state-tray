## 项目解决什么问题

日常使用电脑时，有几个高频困扰：

| 困扰 | 本项目的解法 |
|---|---|
| **密码输错才发现大写锁定开着** | 屏幕常驻显示 CapsLock 状态，余光可辨 |
| **数字小键盘打不出字** | 实时显示 NumLock 状态 |
| **不确定当前是中文还是英文输入** | 输入法状态用红绿双色区分，一眼识别 |
| **系统提示位置固定、容易被忽略** | 面板可自由拖到视线范围内 |
| **游戏时被浮窗遮挡** | 全屏自动隐藏，退出恢复 |
| **浮窗太显眼影响观感** | 智能透明度，闲置自动淡出 |

系统自带的 OSD 提示只在**切换瞬间**闪现，之后无从确认。本项目提供**持续可见**的状态指示，且不占用任务栏、不打断操作。

## 主要功能

### 状态指示
- 大写锁定（CapsLock）
- 数字锁定（NumLock）
- 输入法中/英：中文 **绿底黑字「中」**，英文 **红底黑字「英」**

### 面板外观
- 自定义 PNG 皮肤，逐像素 Alpha 合成，圆角透明无黑边
- 高 DPI 适配，150% / 200% 缩放下不失真
- 五档面板大小：特小 / 小 / 中 / 大 / 特大

### 面板控制
- 左键拖动，位置自动记忆
- 拖动时实时约束在屏幕内，**永不遮挡任务栏**
- 一键回到屏幕右下角

### 智能透明度
- 不透明度 20% ~ 100% 九档可调
- **状态变化时自动恢复完全不透明**，确保看清
- 闲置指定时长后平滑淡出（1 ~ 30 秒可调）
- 「永不透明」开关可彻底关闭淡出

### 游戏模式
- 自动检测全屏应用
- 全屏期间自动隐藏面板，避免遮挡画面
- 退出全屏后自动恢复

### 系统集成
- 常驻系统托盘，任务栏零占用
- 支持开机自动启动（写入 HKCU，无需管理员权限）
- 单实例保护，重复启动自动忽略

## 安装方法

### 方式一：直接运行（推荐）

1. 前往 [Releases](../../releases) 页面，下载最新版 `椰子味的魈宝键盘精灵.exe`
2. 放到任意文件夹（建议 `C:\Users\<用户名>\AppData\Local\KeyStateTray\`）
3. 双击运行

**无需安装**，素材与图标已全部内嵌，单个 exe 即可运行。

### 方式二：从源码构建

需要 **.NET Framework 4.0+**（Windows 7 以上系统默认自带）。

```powershell
git clone https://github.com/xushanzhenxun2233/key-state-tray.git
cd key-state-tray
.\build.bat
```

产物输出到 `dist\椰子味的魈宝键盘精灵.exe`。

### 系统要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 7 / 8 / 10 / 11 |
| 运行环境 | .NET Framework 4.0 或更高（系统默认自带） |
| 权限 | 普通用户即可，无需管理员 |
| 磁盘空间 | 约 1 MB |

## 使用方法

### 首次运行

双击 exe 后，会自动弹出更新日志窗口。点击「我知道了」关闭，面板随即出现在屏幕右侧。

### 基本操作

| 操作 | 方式 |
|---|---|
| 移动面板 | 左键拖动面板 |
| 调整大小 | 右键点击面板 → 特小 / 小 / 中 / 大 / 特大 |
| 回到右下角 | 右键点击面板 → `↘ 回到屏幕右下角` |
| 调整透明度 | 右键点击面板 → 闲置透明度 |
| 永不变透明 | 右键点击面板 → 闲置透明度 → 永不透明 |
| 设置淡出延迟 | 右键点击面板 → 保持完全不透明的时间 |
| 游戏时自动隐藏 | 右键点击面板 → 全屏游戏时自动隐藏 |
| 联系作者 | 右键点击面板 → 点击顶部署名 |
| 显示 / 隐藏面板 | 单击托盘图标 |
| 开关显示项 | 右键托盘图标 → 勾选 |
| 关闭菜单 | 点菜单项 / 点空白处 / 按 `Esc` |
| 退出程序 | 右键托盘图标 → 退出 |

### 开机自动启动

右键托盘图标 → 勾选「开机自动启动」。

写入位置：
```
HKCU\Software\Microsoft\Windows\CurrentVersion\Run
```

> **注意**：自启路径与 exe 所在位置绑定。若移动了 exe 所在文件夹，需重新勾选一次。

### 配置文件

程序会在 exe 同目录生成 `XiaoBaoKeySprite.ini`：

```ini
caps=1            ; 是否显示大写锁定
num=1             ; 是否显示数字锁定
ime=1             ; 是否显示输入法状态
width=180         ; 面板宽度（像素）
opacity=100       ; 闲置透明度 20~100
nofade=0          ; 永不透明 0/1
hold=5            ; 保持完全不透明秒数
hideingame=1      ; 全屏游戏时自动隐藏 0/1
seenversion=1.0.0.0  ; 已查看更新日志的版本
x=-1              ; 面板 X 坐标
y=-1              ; 面板 Y 坐标
```

删除该文件即可恢复全部默认设置。

### 自定义皮肤

将新的 `panel_bg.png` 放到 exe 同目录，即可覆盖内嵌皮肤。

建议规格：
- 正方形或接近正方形的 PNG
- 带透明通道（Alpha）
- 中央预留可绘制区域（用于放置三个状态块）

## 输入输出示例

### 输入 1：硬件按键

| 你的操作 | 面板显示变化 |
|---|---|
| 按下 **CapsLock** | 大写块 灰色「关」→ **蓝色「开」** |
| 按下 **NumLock** | 数字块 灰色「关」→ **蓝色「开」** |
| 按 **Shift**（切换中英文） | 输入法块 **绿底「中」** ⇄ **红底「英」** |

### 输入 2：鼠标操作

**右键点击面板**，弹出菜单：

```
by 椰子味  有问题？单击联系我
─────────────────────────
↘ 回到屏幕右下角
─────────────────────────
特小 / 小 / 中 / 大 / 特大
放大一级 / 缩小一级
闲置透明度  ▸
保持完全不透明的时间  ▸
全屏游戏时自动隐藏        ✓
─────────────────────────
隐藏面板
```

**选择「大」** → 面板立即从 180px 放大到 260px，比例保持不变。

### 输入 3：拖动面板

```
鼠标按住面板 → 拖向左上角 → 面板跟随移动
             → 拖出屏幕边界 → 自动停靠在边缘，无法拖出
             → 松开鼠标 → 位置写入配置文件
```

### 输入 4：启动全屏游戏

```
游戏进入全屏 → 面板自动隐藏（约 150ms 内）
游戏退出全屏 → 面板自动恢复原本位置
```

### 输入 5：透明度效果

设置「闲置透明度 = 50%」后：

```
平时        → 面板半透明（50%），不干扰视线
按 CapsLock → 立即变为完全不透明，持续 5 秒
5 秒后      → 平滑淡回 50%
```

### 输出：托盘提示

鼠标悬停在托盘图标上：

```
键盘状态  Caps:开  Num:开  输入法:中文
```

### 输出：配置文件

调整位置与大小后，`XiaoBaoKeySprite.ini` 自动更新：

```ini
width=260
opacity=50
x=1980
y=920
```

## 常见问题

<details>
<summary><b>杀毒软件报毒怎么办？</b></summary>

本程序包含读取键盘状态、写入开机自启注册表、创建全局窗口等行为，可能被启发式引擎误判。程序**不联网、不收集任何数据、不修改系统设置**。

添加白名单：
```
Windows 安全中心 → 病毒和威胁防护 → 管理设置
→ 排除项 → 添加或删除排除项 → 添加文件夹
→ 选择本程序所在文件夹
```

若已被隔离：
```
病毒和威胁防护 → 保护历史记录 → 找到记录
→ 操作 → 还原，随后立即加入白名单
```
</details>

<details>
<summary><b>输入法状态不同步？</b></summary>

当前通过监听 `Shift` 按键推断中英文切换。若使用**鼠标点击语言栏**切换输入法，程序无法感知。

按一次 `Shift` 可手动校准。
</details>

<details>
<summary><b>面板不见了？</b></summary>

1. 单击托盘图标切换显示
2. 或在托盘菜单选择「面板回到屏幕右下角」
3. 若仍不可见，检查是否进入了全屏游戏（会自动隐藏）
</details>

<details>
<summary><b>能否同时在多台电脑使用？</b></summary>

可以。exe 为单文件，复制到任意 Windows 电脑双击即可运行，配置各自独立。
</details>

## 技术实现

| 项目 | 说明 |
|---|---|
| 语言 | C# 4.0 |
| 框架 | .NET Framework 4.0 |
| 界面 | WinForms + 分层窗口（逐像素 Alpha） |
| 图形 | GDI+ / System.Drawing |
| 编译 | csc.exe 单文件编译 |

### 关键设计

- **透明背景**：使用 `UpdateLayeredWindow` 逐像素合成，而非 `TransparencyKey`，避免边缘锯齿
- **状态读取**：使用 `GetKeyState` 而非 `GetKeyboardState`，不受窗口焦点影响
- **不抢焦点**：窗口设置 `WS_EX_NOACTIVATE`，点击面板不打断当前输入
- **菜单关闭**：面板无焦点导致 WinForms 无法感知外部点击，改用全局低级鼠标钩子
- **边界约束**：基于 `Screen.WorkingArea` 计算，天然排除任务栏
