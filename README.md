# 椰子味的魈宝键盘精灵

> 带桌面宠物的键盘状态悬浮指示器 —— 常驻托盘，实时显示锁定键与输入法

## 项目解决什么问题

日常使用电脑时，有几个高频困扰：

| 困扰 | 本项目的解法 |
|---|---|
| **密码输错才发现大写锁定开着** | 屏幕常驻显示 CapsLock 状态 |
| **数字小键盘打不出字** | 实时显示 NumLock 状态 |
| **不确定当前是哪个输入法** | 直接显示输入法名称，绿/红双色区分中英 |
| **系统提示一闪即逝** | 持续可见的常驻指示，不打断操作 |
| **桌面太单调** | 可互动、可喂食的桌面宠物 |

系统的 OSD 提示只在**切换瞬间**闪现，之后无从确认。本项目提供**持续可见**的状态指示，并且附带一只会自己走动的桌宠。

## 主要功能

### 状态指示

- 大写锁定（CapsLock）
- 数字锁定（NumLock）
- **输入法具体名称**：拼音 / 注音 / 英语 / 日语 / 韩语 / 德语 / 法语 等
  - 中文系输入法：**绿底黑字**
  - 外语输入法：**红底黑字**
  - 直接读取系统键盘布局，准确可靠

### 桌面宠物「魈」

- 站在状态框上方，与框体合并为一个整体窗口
- 8 种表情：吃东西、待机、眨眼、冷漠、睡觉、啧、思考、来吧
- 待机时每 1~3 分钟随机切换表情
- 点击随机说一句游戏原声台词（40+ 句官方原文）
- 双击触发搞怪表情
- 气泡对话独立显示在头顶，不遮挡魈

### 喂食系统

- 饥饿值随时间增长（速度可调：5 秒/点 ~ 10 分钟/点）
- 饥饿时桌面掉落杏仁豆腐，拖到魈身上即可喂食
- 极度饥饿时常驻台词「雪积起来之后，就可以挖着吃了。」
- 该台词会被其他对话打断，对话结束后自动恢复
- 喂食后饥饿归零，播放吃东西动画

### 自动游走

- 每 1~3 分钟沿贝塞尔曲线挪动一小步（约 1/8 屏）
- 2 秒走完，带方向惯性，不会来回反复横跳

### 整点提醒

- 每到整点说一句时段问候
- 分时段文案：早安 / 喝水 / 吃饭 / 休息眼睛 / 收工
- 可在右键菜单开关

### 面板与交互

- 自定义 PNG 皮肤，逐像素 Alpha 合成，无黑边
- 尺寸预设：小 / 中 / 大 / 大肥鸟
- 左键拖动，位置自动记忆，不遮挡任务栏
- 一键回到屏幕右下角
- 智能透明度：出对话时完全不透明，闲置淡出
- 全屏游戏时自动隐藏，退出后回到右下角
- 右键菜单自动跟随系统深色 / 浅色主题

### 系统集成

- 常驻系统托盘，任务栏零占用
- 支持开机自动启动（无需管理员权限）
- 单实例保护，重复启动自动忽略

## 安装方法

### 方式一：直接运行（推荐）

1. 前往 [Releases](../../releases/latest) 页面，下载 `KeyStateTray-v2.0.1.exe`
2. 重命名为 `椰子味的魈宝键盘精灵.exe`（可选）
3. 放到任意文件夹，双击运行

**下载直链：** [KeyStateTray-v2.0.1.exe](https://github.com/xushanzhenxun2233/key-state-tray/releases/download/v2.0.1/KeyStateTray-v2.0.1.exe)

**无需安装**，素材与图标已全部内嵌，单个 exe 即可运行。

### 方式二：从源码构建

需要 **.NET Framework 4.0+**（Windows 7 以上系统默认自带）。

```powershell
git clone https://github.com/xushanzhenxun2233/key-state-tray.git
cd key-state-tray
.\build.bat
```

产物输出到 `dist\椰子味的魈宝键盘精灵.exe`。

### 系统要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 7 / 8 / 10 / 11 |
| 运行环境 | .NET Framework 4.0 或更高（系统默认自带） |
| 权限 | 普通用户即可，无需管理员 |
| 磁盘空间 | 约 3 MB |

## 使用方法

### 首次运行

双击 exe 后，会自动弹出更新日志窗口。点击「我知道了」关闭，面板与魈随即出现在屏幕右下角。

### 基本操作

| 操作 | 方式 |
|---|---|
| 移动窗口 | 左键按住魈或状态框拖动 |
| 点击魈 | 随机换表情 + 说一句台词 |
| 双击魈 | 触发搞怪表情 |
| 喂食 | 拖动桌面上的杏仁豆腐到魈身上 |
| 打开菜单 | 在魈或状态框上右键 |
| 显示 / 隐藏面板 | 单击托盘图标 |
| 快速测试 | 点击菜单顶部署名，打开联系我对话框 |
| 退出程序 | 右键托盘图标 → 退出 |

### 右键菜单

```
by 椰子味  有问题？单击联系我
─────────────────────────────
↘  回到屏幕右下角
─────────────────────────────
小 / 中 / 大 / 大肥鸟
放大一级 / 缩小一级
闲置透明度        ▸
保持完全不透明的时间  ▸
全屏游戏时自动隐藏    ✔
─────────────────────────────
让桌宠打个招呼
自动游走            ✔
饥饿速度          ▸
整点提醒            ✘
喂食 · 杏仁豆腐
─────────────────────────────

```

开关类菜单项状态显示：

- `✔` 绿色加粗 = 已开启
- `✘` 灰色常规 = 已关闭
- `☑` 勾选标记 = 已选中

子菜单支持**右键直接展开**，无需悬停等待。

### 开机自动启动

右键托盘图标 → 勾选「开机自动启动」。

写入位置：`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`

> **注意**：自启路径与 exe 位置绑定。若移动了 exe 所在文件夹，需重新勾选一次。

### 配置文件

程序会在 exe 同目录生成 `XiaoBaoKeySprite.ini`：

```ini
caps=1                ; 是否显示大写锁定
num=1                 ; 是否显示数字锁定
ime=1                 ; 是否显示输入法
width=340             ; 面板宽度
opacity=100           ; 闲置透明度 20~100
nofade=0              ; 永不透明 0/1
hold=5                ; 保持完全不透明秒数
hideingame=1          ; 全屏游戏时隐藏 0/1
showpet=1             ; 是否显示桌宠
petwalk=1             ; 自动游走 0/1
hunger=0              ; 当前饥饿值 0~100
hungerrate=45         ; 饥饿速度（秒/点）
feedcount=0           ; 累计喂食次数
hourlyremind=0        ; 整点提醒 0/1
x=1980                ; 面板 X 坐标
y=920                 ; 面板 Y 坐标
```

删除该文件即可恢复全部默认设置。

## 技术实现

| 项目 | 说明 |
|---|---|
| 语言 | C# 4.0 |
| 框架 | .NET Framework 4.0 |
| 界面 | WinForms + 分层窗口（逐像素 Alpha） |
| 图形 | GDI+ / System.Drawing |
| 编译 | csc.exe 单文件编译 |

### 关键技术点

**透明背景**
使用 `UpdateLayeredWindow` 逐像素合成，而非 `TransparencyKey`，避免边缘锯齿和黑边。

**输入法识别**
通过 `GetKeyboardLayout` 读取前台窗口线程的 HKL，映射为输入法名称。比监听 Shift 键更准确。

**不抢焦点**
窗口设置 `WS_EX_NOACTIVATE`，点击面板不打断当前输入。

**气泡独立窗口**
对话气泡使用单独的透明窗口，不占用面板绘制空间，因此魈的尺寸始终恒定。

**菜单主题跟随**
读取注册表 `AppsUseLightTheme` 判断系统深浅色，配合自定义 `ToolStripRenderer` 实现深色菜单。

**菜单外部点击检测**
面板无焦点导致 WinForms 无法感知外部点击，改用全局低级鼠标钩子。用矩形范围判断点击是否在菜单内，避免子菜单被误判。

**全屏检测**
`GetForegroundWindow` + `GetWindowRect` 比对屏幕区域，排除桌面、任务栏与自身窗口。

## 常见问题

<details>
<summary><b>杀毒软件报毒怎么办？</b></summary>

本程序包含读取键盘状态、写入开机自启注册表、创建全局钩子等行为，可能被启发式引擎误判。程序**不联网、不收集任何数据、不修改系统设置**。

添加白名单：
```
Windows 安全中心 → 病毒和威胁防护 → 管理设置
→ 排除项 → 添加或删除排除项 → 添加文件夹
```
</details>

<details>
<summary><b>输入法显示「其他」？</b></summary>

程序读取系统键盘布局的语言 ID。若某输入法使用了非常见 ID，会显示「其他」。欢迎反馈以便补充映射表。
</details>

<details>
<summary><b>魈不说话了？</b></summary>

检查是否处于全屏游戏模式（面板被隐藏）。退出全屏后会自动恢复。
</details>

<details>
<summary><b>怎么快速测试各项功能？</b></summary>

点击菜单顶部署名，打开「联系我」对话框。二维码下方有 4 个测试按钮：
- 整点报时测试
- 饥饿拉满测试
- 游戏隐藏测试
- 游走测试
</details>

<details>
<summary><b>面板不见了？</b></summary>

1. 单击托盘图标切换显示
2. 或托盘菜单选择「面板回到屏幕右下角」
3. 检查是否进入了全屏游戏
</details>
